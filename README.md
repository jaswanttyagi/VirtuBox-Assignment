# Task Management App — QA Test Case Design



## Application scope

The example app has:
- User Registration & Login
- Create, View, Edit and Delete tasks
- Tasks stored in a database
- Input validation and error handling

## Repository structure

- `testcases.md` — sample test scenarios and detailed test cases
- `potential-bugs.md` — sample risks/bugs identified without executing the app

## How to use

For each feature, think as a real user and test:
1. Normal/valid behaviour (positive)
2. Invalid behaviour (negative)
3. Boundary/unusual conditions (edge)
4. Expected result
5. Business/data/security impact
